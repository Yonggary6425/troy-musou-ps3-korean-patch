# TROY無双 (트로이 무쌍, PS3 일본판 BLJM60307) 비공식 한글패치

코에이 테크모의 PS3 게임 **TROY無双**(트로이 무쌍) 일본판에 적용하는 비공식 한글패치입니다.
**일본어 음성은 그대로 두고** 자막과 메뉴를 한국어로 옮겼습니다.

- 제작: **용가리 (Yonggary6425)**
- 최신 버전: **v1.0** (2026-10-26)
- 유럽판(Warriors: Legends of Troy, BLES01183)용 한글패치는 [별도 저장소](https://github.com/Yonggary6425/warriors-legends-of-troy-ps3-korean-patch)에 있습니다.

이 저장소에는 패치 제작 도구와 기술 문서만 들어 있습니다. 게임 원본 데이터, 일본어 원문, 번역 대본은 포함하지 않습니다.
패치 파일은 [Releases](../../releases)에서 받으세요.

받은 파일이 맞는지 확인하려면 PowerShell에서 다음을 실행해 위 값과 비교하세요.

```powershell
Get-FileHash .\Troy_Musou_JP_KOR_Patch_v1.0.zip -Algorithm MD5
Get-FileHash .\Troy_Musou_JP_KOR_Patch_v1.0.zip -Algorithm SHA256
```

패처 안에는 바뀐 부분(차분)만 들어 있습니다. 나머지는 사용자의 원본 ISO나 게임 폴더에서 읽어 조립합니다.

## 원본

| 항목 | 값 |
|---|---|
| 게임 | TROY無双 (PS3, 일본판) |
| 게임 ID | BLJM60307 |
| 디스크 버전 | 01.02 (`PARAM.SFO`의 `VERSION`) |
| 파일 형식 | 복호화(decrypted)된 ISO, 또는 ISO를 압축 해제한 게임 폴더 |

> 패처는 적용 전에 게임 ID와 바꿀 원본 파일 107개의 SHA-1을 하나씩 확인합니다. ISO 전체 해시는 덤프 도구에 따라 다를 수 있으므로, 패처가 거부하지 않으면 그대로 쓰셔도 됩니다.

> 유럽판·북미판 등 다른 판본이나 암호화된 ISO에는 적용되지 않습니다. 패처가 자동으로 확인한 뒤 거부합니다.

## 적용 방법

`TroyMusouKOR_Patcher.exe` 위에 **게임 폴더** 또는 **ISO 파일**을 끌어다 놓습니다. (또는 실행한 뒤 창에 끌어다 놓고 Enter)

### 게임 폴더에 적용 (RPCS3 권장)

1. `PS3_GAME` 폴더가 들어 있는 폴더(또는 `PS3_GAME` 폴더 자체)를 끌어다 놓습니다.
2. 바뀌는 원본 파일은 게임 폴더 안 `TroyKOR_backup` 폴더에 백업한 뒤 적용합니다.
3. `완료!`가 나오면 끝입니다. 이미 패치된 폴더를 다시 넣으면 원본으로 되돌릴 수 있습니다.

### ISO 파일에 적용

1. 원본 ISO를 끌어다 놓습니다.
2. 저장 방식을 고릅니다.
   - `[1]` 새 ISO로 저장 (권장): 원본은 그대로 두고 `… [KOR].iso`를 새로 만듭니다. 같은 이름의 파일이 있으면 덮어씁니다.
   - `[2]` 원본 ISO에 바로 적용: 빠르지만 원본이 바뀝니다.
3. `완료!`가 나오면 끝입니다.

ISO 안의 파일 목록 세 가지(ISO9660, Joliet, UDF)를 모두 고칩니다. 그래서 패치한 ISO를 RPCS3에서 바로 실행해도 되고, 반디집·WinRAR·7-Zip 등 어떤 프로그램으로 풀어도 한글판 파일이 나옵니다.
적용 후에는 결과 파일을 다시 읽어 검증합니다. 이미 패치된 ISO나 폴더에 다시 실행해도 안전합니다.

### 실행 시 참고

- 일본판에는 일본어 데이터만 들어 있어서, 시스템 언어 설정과 관계없이 한글이 나옵니다.
- 결정·취소 버튼 배치는 일본판 원래 설정(○ 결정)을 따릅니다.
- 게임 안에서 HDD 설치를 이미 했다면, 설치 데이터를 지우고 다시 설치하세요.
- 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 개인 제작 프로그램이라 나오는 경고입니다.

## 한글화 범위

### 텍스트
- 3,247줄
  - 메뉴·도움말·아이템·로딩 팁 1,727줄
  - 인게임 대사 762줄
  - 동영상 자막 512줄
  - 목표·튜토리얼 246줄
- **동영상 자막**: 일본판은 일본어 음성에 맞춰 자막을 유럽판과 다르게 나누고 내용도 다듬었습니다. 그래서 일본어 대본에서 새로 번역했습니다.
- **메뉴·인게임 대사·목표**: 유럽판 한글패치의 번역을 일본판 구성(일본판 전용 문구, 줄 길이)에 맞춰 옮겼습니다. 일본판에만 있는 문구(출혈 표현 안내 등)는 새로 번역했습니다.
- 인명·지명은 그리스어 원음 표기를 따랐습니다. 예: 아이아스, 헥토르, 헬레네, 트로이아, 뮈르미돈
- 인물 관계에 따라 하게체, 하오체, 해라체를 나눠 고대 서사시 분위기를 살렸습니다.

### 글꼴
- 일본판 글꼴(`fonts_JP.g1n`)의 두 글꼴에 한글을 추가했습니다.
  - 본문(굵은 명조): 본명조(Noto Serif KR) Black
  - 장식 글꼴(입체 음영): 나눔고딕 ExtraBold
- 원본의 외곽선, 그림자, 입체 음영을 분석해 한글에도 같은 방식으로 적용했습니다.
- 동영상·컷신·대사 자막은 표시 배율을 0.8 → 0.9로 올려 원래보다 약 12% 크게 보입니다.

### 이미지
- 장·도전 모드 제목, 메인 메뉴, 인물 이름표, 화면 제목 등 유럽판 한글패치의 그림 글자를 일본판 화면 구성에 맞춰 옮겼습니다.
- 일본판 전용 화면은 일본판 배치에 맞춰 새로 그렸습니다.
  - 일시정지 메뉴, 메인 메뉴 기록, 타이틀 화면
- 일본판에만 있는 그림 글자 묶음을 한글로 다시 그렸습니다.
  - 기술 화면 항목 제목: 동작, 빠른 공격, 집중 공격 연계, 기절 공격 후 무기 던지기 등
  - 보조 목표, 고유 아이템, 보상 합계 등

### 그대로 둔 항목
- 음성 (일본어)
- 타이틀 로고(TROY無双), 저작권 표기
- 갤러리 원화
