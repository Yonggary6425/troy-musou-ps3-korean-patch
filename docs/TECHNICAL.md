# 기술 문서 (일본판 고유 구조)

일본판 TROY無双(BLJM60307)은 유럽판 Warriors: Legends of Troy(BLES01183)와 엔진이 같습니다. 아래 형식은 유럽판과 같으므로 [유럽판 기술 문서](https://github.com/Yonggary6425/warriors-legends-of-troy-ps3-korean-patch/blob/main/docs/TECHNICAL.md)를 보세요.
- INI 텍스트(UTF-16BE)
- G1N 글꼴
- cpkg/mpkg 묶음
- G1T 텍스처
- 차분 형식 `TROYKO01`

이 문서는 일본판에서 다른 점과, 일본판 작업에서 새로 알아낸 내용을 정리합니다.

## 1. 언어 구성

- 데이터는 일본어 한 벌뿐입니다(`Localization/JPN/`, `*_JPN.cpkg/mpkg/lpkg`). 그래서 시스템 언어와 관계없이 이 데이터를 읽습니다.
- `Config/LangConfig.ini` 설정은 다음과 같습니다.
  - `Font=fonts_JP.g1n`
  - `FontFormatPackage=FontData_JPN`
- 결정 버튼은 ○입니다. 패치는 이 설정을 바꾸지 않습니다.

## 2. 텍스트 키

| 파일 | 유럽판과의 관계 |
|---|---|
| `UIStringsJPN.ini` (1,727줄) | 섹션·키가 영어판과 같음 |
| `ScenarioXXXJPN.ini` (246줄) | 키가 영어판과 같음 |
| `SubTitleXXXJPN.ini` (762줄) | 영어 키 뒤에 `_JP`가 붙음. 예: `00541X_G10_Patroklos_JP[0]` |
| `SubTitleFMVXXXJPN.ini` (512줄) | 일본어 음성에 맞춰 자막을 다르게 나눔. 줄 수·내용이 영어판과 다름 |

- 앞의 세 종류는 키를 대응시켜 유럽판 번역을 옮겼습니다(`build_ini.py`).
- 동영상 자막은 일본어 원문에서 새로 번역했습니다.
- 유럽판의 문장부호 태그(`{’}`, `{—}`, `{…}` 등)는 일본판 글꼴에 맞춰 실제 문자로 바꿨습니다.
- 일본판에만 있는 키(`Title.ViolenceMessage` 등)는 따로 번역했습니다(`fix_missing.py`).

## 3. 글꼴 (`fonts_JP.g1n`)

| 번호 | 크기 | 원본 | 한글 |
|---|---|---|---|
| 0 | 30px | 굵은 명조 1,366자. ASCII 공백과 `, - * + [ ] ^`가 없음 | 본명조 Black, 외곽선 1px + 그림자. 팔레트 8–15번(채움)에 맞춰 다시 매핑 |
| 3 | 44px | 입체 음영 고딕, 가타카나와 일부 한자 87자 | 나눔고딕 ExtraBold, 입체 음영 |
| 1, 2, 4–6 | | 기호·아이콘 | 변경 없음 |

- 0번 글꼴은 메뉴·자막·대사 등 거의 모든 글자에 쓰입니다.
- 화면별 크기는 UI 장면의 `m_nScale`로 정합니다.
- 줄 길이는 이 글꼴의 진행 폭으로 계산했습니다(`widths.py`).
  - 대사 576px(두 줄은 620px)
  - 동영상 자막 592px
  - 목표 360px

## 4. 그림 글자

### 유럽판에서 옮긴 텍스처
- 일본판과 유럽판은 텍스처 이름·크기·형식이 같습니다.
- 유럽판 한글패치에서 바뀐 텍스처 38장을 그대로 옮겼습니다(`transplant.py`).
- 일본판 배치가 다른 3장은 일본판 그림 위에 다시 그렸습니다(`fix_tex.py`).
  - `Pause_Title`
  - `Main_BG`(기록 항목)
  - `Title_Parts`(로고는 일본판 그대로)

### 일본판 전용 그림 글자 묶음 `Light00`
`CommonMasterPackage.cpkg`의 `Light00`(256×256, DXT5)에는 일본판에서만 쓰는 단어가 그림으로 들어 있습니다.

- **들어 있는 단어:** サブミッション, ミッション, ユニークアイテム, 前転, Kleos, 後の武器投げ, 崩し攻撃, 強攻撃, アクション, コンボ, 弱攻撃, 前転攻撃, 斧・棍棒・剣, 槍, 報酬合計, 通算戦績
- **쓰이는 방식:** 기술 화면(Moves)의 항목 제목이 텍스트가 아니라 이 그림에서 잘라 낸 조각입니다.
  - 장면 파일에 `<Strings:ComboList.Move.Spear>` 같은 텍스트 위젯이 있습니다.
  - 그러나 실제로 보이는 것은 `UITextures00CommonNew.Texture.Light00`을 참조하는 이미지 위젯입니다(`m_nU`, `m_nV`, `m_nSampleWidth/Height`).
  - 그래서 INI를 고쳐도 제목이 바뀌지 않습니다.
- **조각을 이어 붙인 제목:** 「崩し攻撃後の武器投げ」 = 「崩し攻撃」 + 「後の武器投げ」, 「強攻撃コンボ」 = 「強攻撃」 + 「コンボ」
- **한글로 다시 그린 방법:** 각 단어를 원래 자리에 같은 크기로 그렸습니다(`fix_light00.py`).
  - 조각을 이어 붙였을 때 높이·색·가로 비율이 같도록 기준 조각(한자 단어)에 맞췄습니다.
  - 장면 파일의 좌표는 바꾸지 않았습니다.

## 5. UI 장면 (`*.lpkg`)

- `UI/Scenes/*/*.lpkg`는 cpkg와 같은 압축 컨테이너이고, 안에 Lua 5.1 바이트코드 청크가 들어 있습니다.
  - 형식: 빅엔디언, 정수·size_t 4바이트, 숫자 4바이트 float
- 장면 정의는 상수 표(문자열·숫자)와 `SETTABLE` 명령으로 위젯 속성을 채웁니다.
- 같은 함수 안의 같은 숫자는 상수 하나를 함께 씁니다.
- **자막 배율:** `<SubtitleLogic:Text>`가 들어 있는 함수에서 숫자 상수 0.8을 찾습니다.
  - 그 상수를 참조하는 명령이 모두 `SETTABLE … "m_nScale"`인지 확인한 뒤, 상수 값만 0.9로 바꿨습니다(`luac51.py`, `scan_scale.py`, `fix_subscale.py`).
  - 대상: `UI`·`Challenges`·`Scenario`·`Loading` 장면의 동영상 자막, 로딩 영상 자막, 인게임 대사(이름·쌍점 포함)
- **넘어가기 안내:** `Skip_Text`는 화면 오른쪽 고정 위치에서 시작하므로, 문구 길이를 원문(「スキップ」)과 같게 맞췄습니다.

## 6. ISO와 UDF

일본판 ISO는 ISO9660 + Joliet + UDF 2.50 브리지 형식입니다.
- 볼륨 기술자: 섹터 19–21에 `BEA01`, `NSR03`, `TEA01`이 있습니다.
- UDF 구조: 파티션 시작 섹터 416, 메타데이터 파티션 맵이 있습니다.
- 판독 범위: RPCS3는 Joliet를 읽고, 반디집 등 압축 프로그램은 UDF를 읽습니다.

패처는 세 목록을 모두 고칩니다. UDF 처리 방법은 유럽판 기술 문서의 「UDF 브리지」 절과 같습니다(`tools/patcher/apply/udf.go`).
- 메타데이터 파일로 블록 대응표를 만듭니다.
- File Entry의 할당 기술자·크기를 고칩니다.
- 태그 CRC를 다시 계산합니다.
- 파티션 길이를 늘리고, 끝 Anchor를 둡니다.

`tools/diag`는 ISO의 볼륨 기술자, PS3 영역 표, 대상 파일의 두 디렉터리 기록, UDF 구조를 텍스트로 출력하는 진단 도구입니다.
