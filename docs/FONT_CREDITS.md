# 글꼴 출처

한글 글리프는 다음 글꼴로 그린 뒤 게임 비트맵 글꼴(`fonts_JP.g1n`) 형식으로 바꿔 넣었습니다.
그림 글자(메뉴 제목, 기술 화면 항목 제목 등)도 같은 글꼴로 그렸습니다. 유럽판 한글패치에서 옮겨 온 그림은 유럽판 글꼴(IBM Plex Sans KR, 고운돋움, 본명조)을 썼습니다.

| 글꼴 | 저작권 | 사용한 곳 |
|---|---|---|
| Noto Serif KR (본명조) Black | Copyright 2017–2021 Google LLC / Adobe | 0번 글꼴 (본문·자막), 일본판 그림 글자 |
| 나눔고딕 ExtraBold (NanumGothic) | Copyright 2010 NAVER Corporation | 3번 글꼴 (입체 음영 장식체) |
| IBM Plex Sans KR | Copyright © 2017 IBM Corp. | 유럽판에서 옮겨 온 그림 글자 |
| Gowun Dodum (고운돋움) | Copyright 2021 The Gowun Project Authors | 유럽판에서 옮겨 온 그림 글자 |

모든 글꼴은 **SIL Open Font License 1.1**로 배포됩니다.

- 라이선스 전문: https://openfontlicense.org/open-font-license-official-text/
- 받은 곳: https://github.com/google/fonts (`ofl/notoserifkr`, `ofl/nanumgothic`, `ofl/ibmplexsanskr`, `ofl/gowundodum`)

이 패치는 글꼴 파일 자체를 배포하지 않습니다. 게임 내 비트맵으로 바꾼 결과만 들어 있으며, 원 글꼴의 저작권 표기를 여기에 남깁니다.

## 원본 글꼴을 고른 이유

| 원본 글꼴 | 특징 | 고른 한글 글꼴 |
|---|---|---|
| 0번 (30px) | 굵은 명조, 흰 글자에 검은 외곽선 | 획 대비가 비슷한 본명조 Black |
| 3번 (44px) | 굵은 고딕, 입체 음영 (가타카나 위주) | 획이 단단한 나눔고딕 ExtraBold |
